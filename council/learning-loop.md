# Skill: Learning Loop for New Concepts

## When to use

When a new concept appears in the work (e.g., "API route", "schema",
"component", "auth") and understanding it will affect a real decision.

## Process

### 1. Define

- Where did this concept show up in the project?
- What decision depends on understanding it?

### 2. Explain

- Simple definition in 2–3 sentences.
- One tiny example relevant to the current stack.

### 3. Connect

- How it fits into the current app architecture.
- How it compares to at least one alternative.

### 4. Apply

- Propose a tiny exercise inside one of the three projects.
- Keep it under 30 minutes.

### 5. Reflect

- User summarises in their own words.
- Capture any new rule for CLAUDE.md or agent files.

## Output format

- **What it is** (2–3 sentences)
- **Why it matters right now**
- **Example** (in context of current project)
- **Exercise** (small and concrete)
- **Your summary** (user fills this in)
